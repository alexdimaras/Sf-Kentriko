# SF Κέντρο — Project

> Εφαρμογή back office για **specialforces.gr** και **stratiotikaeidi.gr**.
> Έκδοση **1.3.0** · Node 22 · χωρίς paid AI · τοπικά σε ένα PC **ή** ως κοινός διακομιστής (cloud / ένα PC) για όλους.

---

## 1. Σκοπός

| Site | Ρόλος |
|---|---|
| **specialforces.gr** (`sf`) | Όλο το εύρος, μαζί με όπλα. **Η τιμή του είναι η σωστή** όταν διαφέρουν τα δύο sites. |
| **stratiotikaeidi.gr** (`st`) | Μόνο ρουχισμός/εξοπλισμός. Χρησιμοποιείται για διαφημίσεις Google/Meta, άρα πρέπει να είναι «καθαρό» από απαγορευμένα προϊόντα. |

Δύο φυσικά μαγαζιά στον Πειραιά. Το πρόγραμμα **δεν γράφει ποτέ** στα sites· παράγει αρχεία (CSV για WooCommerce, Excel, σελίδες HTML) που ανεβάζει ο χρήστης.

### Βασικές απαιτήσεις (σε ισχύ)
- Αυτόματη καταχώρηση νέων προϊόντων **με έγκριση** του Alex.
- Τίτλοι ΚΕΦΑΛΑΙΑ χωρίς τόνους, μοτίβο `ΕΙΔΟΣ BRAND ΜΟΝΤΕΛΟ…`.
- Περιγραφή = ο τίτλος σε Title Case + το επίσημο κείμενο.
- Χωρίς paid AI (προαιρετικά τοπικό Ollama).
- Αρχεία λήψης διαδραστικά (σελίδα στο Chrome) **και** Excel.
- Έρευνα ανταγωνισμού κάθε μέρα, αυτόματα, για **όλα** τα προϊόντα.
- Κανόνες διαφημίσεων από τις πολιτικές Google/Meta.
- Έξυπνοι αντιπρόσωποι: το πρόγραμμα βρίσκει μόνο του τα στοιχεία, ο χρήστης διορθώνει.
- **Ασφάλεια:** «να υπάρχει μεγάλη ασφάλεια, δεν θέλω να διαρρεύσουν κωδικοί».
- Στην έρευνα αγοράς **όχι χαμηλές τιμές από εξαντλημένα** προϊόντα.
- **1.3.0:** η τιμή αλλάζει μόνο όταν συμφωνούν ≥2 καταστήματα· ύποπτες τιμές (κάτω από το κόστος μας, πολύ κάτω από
  τους άλλους / τη λιανική αντιπροσώπου) φαίνονται αλλά δεν μετράνε· ευδιάκριτα «εμείς vs ανταγωνιστές».
- **1.3.0:** ό,τι λείπει συμπληρώνεται **αυτόματα μέσα στην εφαρμογή** (όχι στο site) και περιμένει **έγκριση** —
  η εφαρμογή δεν «δείχνει λάθη», τα διορθώνει, με όσο το δυνατόν λιγότερα λάθη (πηγές + έλεγχος + σιγουριά).
- **1.3.0:** κοινά δεδομένα για όλους τους υπολογιστές, ακαριαία· πιο ελαφριά.
- **1.3.0:** πρόσβαση **από κινητό** και από όλα τα PC, συγχρονισμένα — **δωρεάν** («δεν θέλω να πληρώσω») και
  χωρίς PC ανοιχτό μετά το κλείσιμο του μαγαζιού → δωρεάν διακομιστής στο cloud (Oracle Always Free) ή, χωρίς
  κάρτα, ένα PC του μαγαζιού ως διακομιστής για τις ώρες λειτουργίας.

## 2. Αρχιτεκτονική

**Δύο λειτουργίες, ίδιος κώδικας:**
- **Τοπική** (προεπιλογή): όπως παρακάτω — ένα PC, `127.0.0.1`, token ανά εκκίνηση, PIN.
- **Διακομιστή** (`SFK_MODE=server`, `SF-Kentro-Server.cmd` ή Docker): ακούει στο δίκτυο, χρήστες με κωδικό, sessions
  (cookie HttpOnly/SameSite=Strict + CSRF token), ρόλοι, ζωντανές ενημερώσεις (SSE `/api/events`) σε όλες τις οθόνες.
  Οδηγίες: `DIAKOMISTIS-CLOUD.txt`, αρχεία: `app/Dockerfile`, `deploy/docker-compose.yml` (+ Caddy για https).
- **Δωρεάν εγκατάσταση διακομιστή:** (Α) Oracle Cloud Always Free (Ubuntu, A1.Flex 1 OCPU/6 GB): `SF-Kentro-Cloud.cmd`
  από τα Windows πακετάρει `app`+`deploy` (tar), τα ανεβάζει (scp) και τρέχει `deploy/install-server.sh <διεύθυνση>`
  (Docker, swap σε μικρή μνήμη, πόρτες 80/443 στο iptables της Oracle, `.env`, build, κωδικός αρχικής ρύθμισης,
  έλεγχος https). Διεύθυνση: subdomain σας ή duckdns.org (όχι sslip.io/nip.io: εκτός Public Suffix List → όρια
  Let's Encrypt). (Β) `SF-Kentro-Server.cmd` σε ένα PC του μαγαζιού: LAN, ανοίγει και τον browser.
- **Κινητό:** responsive ≤820px (πάνω μπάρα, κάτω μπάρα καρτελών, μενού-φύλλο, κάρτες στη θέση πινάκων), PWA
  (`manifest.webmanifest`, εικονίδια, «Προσθήκη στην αρχική οθόνη»), συγχρονισμός όταν ξυπνάει/ξαναβρίσκει δίκτυο
  (catch-up), «Μείνε συνδεδεμένος» (12 ώρες αδράνειας), Ρυθμίσεις → Κινητό με QR (`GET /api/connect`, `/api/qr`).
- **Router:** κάθε οθόνη αποδίδεται σε καινούργιο `<main>`· μια αργή οθόνη δεν ζωγραφίζει ποτέ πάνω από την επόμενη.

```
┌───────────────────────────── Windows PC ─────────────────────────────┐
│  SF-Kentro.cmd → runtime\node.exe → app\server.js                    │
│                                                                      │
│  Chrome/Edge  ◄── http://127.0.0.1:17321 ──►  server.js (Node 22)    │
│  (UI, vanilla JS)        token + Origin check     │                  │
│                                                   ▼                  │
│                                    lib/*  ──► JSON store (Έγγραφα\SF-Kentro)
│                                       │                              │
└───────────────────────────────────────┼──────────────────────────────┘
                                        ▼
        sf / st (Woo Store API) · ανταγωνιστές (Woo/Shopify) · αντιπρόσωποι (feed/B2B/PDF/Excel)
        μηχανές αναζήτησης (DuckDuckGo → Bing) μόνο για την αναζήτηση αντιπροσώπων
```

- **Server:** `server.js` — HTTP server στο `127.0.0.1:17321` (`SFK_PORT` το αλλάζει). Χωρίς frameworks.
- **UI:** `public/` — vanilla JS, hash router (`#/view?tab=…`), κάθε οθόνη = `public/js/v-*.js`.
- **Αποθήκευση:** JSON αρχεία με cache (`lib/store.js`: `read/write/update/forget`), αντίγραφο ασφαλείας ημερήσιο (14 μέρες).
- **Background jobs:** `lib/jobs.js` — ένα job κάθε τύπου τη φορά, με progress/log/cancel· το UI τα παρακολουθεί (`watchJob`).
- **Packaging:** φορητό zip = `runtime\node.exe` (Node 22) + `app\` (κώδικας + `node_modules`).

## 4. Λειτουργίες

### 4.1 Σήμερα
Λίστα εκκρεμοτήτων ταξινομημένη κατά σοβαρότητα (`dashboard.js`): έτοιμες διορθώσεις για έγκριση, **μόνο** όσα
προβλήματα ελέγχων δεν διορθώνονται αυτόματα, πωλήσεις με ζημιά, νέα προϊόντα, παραγγελίες, αλλαγές τιμών αντιπροσώπων,
πτώσεις τιμών ανταγωνιστών, προτάσεις αντιπροσώπων, υπενθύμιση PIN.

### 4.1β Διορθώσεις (1.3.0)
`fixes.js` υπολογίζει για κάθε προϊόν αλλαγές `{field, from, to, why, source, level}`:
- **Τίτλος** (κενά, κεφαλαία, τόνοι, ελληνικά/λατινικά = high· λατινικές ελληνικές λέξεις, ορθογραφία, είδος πρώτο = medium).
- **Περιγραφή / σύντομη / φωτογραφίες / μάρκα / EAN** από: το ίδιο προϊόν στο άλλο site (high) → τιμοκατάλογο
  αντιπροσώπου (ίδιος κωδικός/EAN = high, όνομα = medium) → σελίδα προϊόντος αντιπροσώπου (κρατιέται 30 μέρες,
  1,5 s ανά σελίδα, ≤150/εκτέλεση, ≤60/μέρα αυτόματα) → σελίδα που δίνει ο χρήστης. Κάθε πηγή περνά τον ίδιο αυστηρό
  έλεγχο «ίδιο προϊόν» με την έρευνα αγοράς· τηλέφωνα/email/τιμές/«κατάστημά μας»/χονδρική αφαιρούνται. EAN μόνο με
  σωστό ψηφίο ελέγχου. Ποτέ κείμενα ανταγωνιστών.
- **Τιμή** ΣΤ = SF, **κατηγορία** από παρόμοια προϊόντα, **διαφημίσεις** (πρόχειρο / εκτός Google Shopping).
- Αποφάσεις (`fixes` store) με hash της πρότασης· «Έγκριση όλων των σίγουρων»· **ένα** CSV ενημέρωσης ανά site.
- Δείκτης ποιότητας καταλόγου (0–100) τώρα / μετά τις διορθώσεις.

### 4.2 Προϊόντα & Έλεγχοι
- Ανάγνωση sf/st με Store API: σελιδοποίηση, **αυξητική** ανάγνωση (`after` + `modified_gmt`), μεταβλητά προϊόντα (`type=variation`), εβδομαδιαία πλήρης.
- Σύνδεση sf↔st, διαφορές τιμών (η τιμή του SF κερδίζει).
- Έλεγχοι: τίτλοι (ορθογραφία, μεικτά αλφάβητα, CAPS), περιγραφές, φωτογραφίες, κατηγορίες, τιμές, **κανόνες διαφημίσεων** (όπλα, αερόβολα, μαχαίρια κ.λπ. → κρύβονται από Google/Meta).
- Διορθώσεις με αρχείο CSV ενημέρωσης· δυνατότητα «αγνόησης» ευρημάτων.

### 4.3 Νέα προϊόντα
Εισαγωγή από URL/κείμενο/τιμοκατάλογο → πρόχειρο → έλεγχος τίτλου, κατηγορίας, τιμής (με έρευνα αγοράς), ελέγχου διαφημίσεων → **έγκριση** → CSV εισαγωγής (με GLA meta, brand attribute).

### 4.4 Αντιπρόσωποι
- Στοιχεία, μάρκες, παράδοση, όροι· «Συμπλήρωση από το site» (τηλέφωνο, email, ΑΦΜ, feeds, B2B, μάρκες).
- Τιμοκατάλογος από: **feed/XML/CSV σε link**, **δημόσιο κατάλογο**, **B2B με κωδικό** (WooCommerce), **PDF/Excel**.
- Παραγγελίες προς αντιπροσώπους (email).
- **Προτάσεις νέων αντιπροσώπων** (νέο στην 1.2.0) — βλ. §6.

### 4.5 Τιμές αγοράς
- ~24 προεπιλεγμένοι ανταγωνιστές (SEED), προσθήκη/ανίχνευση πλατφόρμας.
- Κατεβαίνει ολόκληρος ο κατάλογος κάθε ανταγωνιστή και συγκρίνονται **όλα** τα προϊόντα (αυτόματα την πρώτη φορά της μέρας).
- Matching: `features`/`candFeatures`, αντεστραμμένο ευρετήριο, αυστηρός κανόνας «Ίδιο» vs «Παρόμοιο;» (χρειάζεται επιβεβαίωση).
- Στρατηγικές τιμής: min, min−%, median, median−%· στρογγυλοποίηση ,90· **κατώτατο όριο από κόστος**.
- Λεπτομέρειες στο §5.

### 4.6 Αναφορές
Όλες οι λίστες (προϊόντα, έλεγχοι, τιμές αγοράς, αλλαγές, τιμοκατάλογος) έχουν:
- **«Άνοιγμα σελίδας»** → ανοίγει σε καρτέλα Chrome από `http://127.0.0.1:…/r/<αρχείο>?k=<κλειδί>`: κάρτες/πίνακας, αναζήτηση, facets, KPI φίλτρα, πλαίσιο λεπτομερειών, μεγέθυνση φωτογραφίας, αντιγραφή, CSV, εκτύπωση, σκούρο θέμα. Δουλεύει και ως αρχείο `file://` (αποθηκεύεται στο `exports/`).
- **Excel** μόνο για εξαγωγή.

### 4.7 Ρυθμίσεις
Sites · Τιμές · Όπλα & διαφημίσεις (κανόνες επεξεργάσιμοι) · Νέα προϊόντα · Κατηγορίες · Τοπικό AI · **Κινητό**

## 5. Έρευνα αγοράς — λογική (v3, 1.3.0)

`LOGIC_VERSION = 3`. Πάνω από τα παρακάτω (v2):
- `stats(list, { ours, costVat, rrp })`: κάθε προσφορά παίρνει `flag` (used / suspect / out / stale / high / foreign /
  similar / ignored). **Ύποπτη** = κάτω από κόστος με ΦΠΑ, ή `suspectPct`% (30) κάτω από τη λιανική αντιπροσώπου, ή
  κάτω από τη διάμεσο των **άλλων** (leave-one-out, 3+), ή με 2 καταστήματα όταν η δική μας τιμή πλησιάζει το άλλο.
- `decision()`: `lower` (≥`minShops`=2 φθηνότερα & >5% πάνω από διάμεσο) · `raise` (≥2 ακριβότερα & >15% κάτω, **ή
  ζημιά**: τιμή < κόστος με ΦΠΑ → κατώτατο όριο) · `watch` (λίγα στοιχεία) · `hold` · `nodata`· αλλαγές <1% αγνοούνται·
  `reason` σε απλά ελληνικά, `rank/of`, `vsMedian`.
- `run()`: ένας κατάλογος ανταγωνιστή στη μνήμη τη φορά· αλλαγές τιμών μόνο για προϊόντα με απόθεμα.
- Κόστος + λιανική αντιπροσώπου (`costs`: `{cost, rrp, source}`) ενημερώνονται αυτόματα σε κάθε ανανέωση τιμοκαταλόγου.

### v2

1. **Matching** μόνο «Ίδιο» μετράει· παρόμοια → ουρά επιβεβαίωσης (η απάντηση θυμάται).
2. **Στατιστικά** (`stats()`) εξαιρούν:
   - μη-ακριβή/αγνοημένα, ξένα (αν ενεργό «μόνο ελληνικά»),
   - **εξαντλημένα** (`inStock === false`) — «εξαντλημένο: δεν μετράει»,
   - **παλιές** τιμές (> 7 μέρες, εκτός χειροκίνητων),
   - **ακραίες** (με ≥3 προσφορές: < 0,5× ή > 2× της διαμέσου).
3. **Confidence:** ≥3 καταστήματα `high`, 2 `medium`, 1 `low`.
4. **bigDrop:** προτεινόμενη < 80% της τωρινής· **careful:** bigDrop με < 2 καταστήματα.
5. **Export τιμών:** τα `careful` δεν μπαίνουν χωρίς ρητή επιβεβαίωση (Άκυρο / Μαζί κι αυτά / Μόνο τα υπόλοιπα). Για κοινά προϊόντα γίνεται και αρχείο για το st με την ίδια τιμή του sf.
6. Αν **όλοι** οι άλλοι είναι εξαντλημένοι → εμφανίζεται «δεν χρειάζεται μείωση τιμής».
7. `LOGIC_VERSION = 2`: στην πρώτη εκκίνηση μετά από αναβάθμιση ξαναϋπολογίζονται τα αποθηκευμένα αποτελέσματα.

Απόδοση (δοκιμή): 10 ανταγωνιστές × 3.500 προϊόντα ≈ 9–10 s, ≈ 800 MB RSS (1.2.0).
1.3.0, ίδια συνθετικά δεδομένα: έλεγχοι + έρευνα + διορθώσεις ≈ 9 s, **246 MB** αιχμή (1.2.0 χωρίς διορθώσεις: 353 MB).

## 6. Αυτόματη αναζήτηση αντιπροσώπων (`supplierfind.js`)

**Στόχοι:** (α) μάρκες που πουλάμε χωρίς αντιπρόσωπο, (β) μάρκες που έχουν ≥2 ανταγωνιστές (ή ≥8 προϊόντα) και εμείς όχι.

**Ροή ανά μάρκα:** έως 3 αναζητήσεις (ελληνικά + αγγλικά) → DuckDuckGo, με εναλλακτική Bing · φίλτρο (marketplaces/social/δικά μας domains) · βαθμολογία (λέξεις αντιπρόσωπος/εισαγωγέας/χονδρική, αναφορά μάρκας, .gr, επανάληψη σε αναζητήσεις) · **άνοιγμα των 3 καλύτερων** (`supplierinfo.lookup`) για έλεγχο ότι έχουν τη μάρκα, B2B, στοιχεία επικοινωνίας.

**Κατηγορίες αποτελεσμάτων:** distributor · maker (site κατασκευαστή: «ρώτα ποιος φέρνει τη μάρκα») · competitor.

**Έγκριση:** `Έγκριση` → δημιουργεί αντιπρόσωπο (ή προσθέτει τη μάρκα σε υπάρχοντα) και ανοίγει τη φόρμα · `Όχι αυτός` · `Ποτέ αυτό το site` · `Δεν με ενδιαφέρει η μάρκα`.

**Ρυθμός:** 4–7 s μεταξύ αναζητήσεων· 40 μάρκες/εκτέλεση· εβδομαδιαία αυτόματη εκτέλεση (αν μπλοκαριστεί → ξαναδοκιμάζει μετά από 6 ώρες). Δοκιμές με mock μηχανή αναζήτησης (`SFK_SEARCH_DDG`, `SFK_SEARCH_BING`, `SFK_SEARCH_FAST`).

## 7. Ασφάλεια

| Μέτρο | Λεπτομέρεια |
|---|---|
| Δίκτυο | Ακούει μόνο `127.0.0.1`· έλεγχος Host· **403 σε ξένο Origin** |
| Token | Τυχαίο token ανά εκκίνηση, μπαίνει στο `index.html`, στέλνεται ως `X-SFK` (σύγκριση `safeEq`) |
| Headers | CSP, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY` |
| Σελίδες αναφοράς | Κλειδί ανά αρχείο + CSP με nonce, χωρίς inline handlers, `connect-src 'none'` |
| PIN | 6–32 χαρ., όχι τετριμμένα· **scrypt (N=2¹⁵)**· δεν αποθηκεύεται |
| Διακομιστής (1.3.0) | Χρήστες με scrypt, 5 λάθη → αναμονή (ανά χρήστη & IP), session cookie HttpOnly/SameSite=Strict(/Secure) με hash στον δίσκο, CSRF token ανά session σε κάθε κλήση, έλεγχος Host (`SFK_ALLOWED_HOSTS`) και Origin, ρόλοι admin/staff, λήξη από αδράνεια, HSTS πίσω από https |
| Κινητό (1.3.0) | «Μείνε συνδεδεμένος» = 12 ώρες αδράνειας (μόνο με επιλογή του χρήστη)· ο admin βλέπει κάθε συσκευή και αποσυνδέει μία (`POST /api/users/session-end`)· αντίγραφο όλων των δεδομένων μόνο από admin, με τυχαίο όνομα, σβήνεται σε 15′ στον διακομιστή, και η λήψη του ελέγχει ξανά τον ρόλο· κωδικός B2B από άλλο PC → καθαρό μήνυμα «γράψε τον ξανά» |
| Brute force | 5 λάθη → αναμονή 60 s που διπλασιάζεται· **επιμένει μετά από επανεκκίνηση** |
| Auto-lock | 30′ (ρυθμιζόμενο) — επιβάλλεται **στον server** (HTTP 423), όχι μόνο στην οθόνη. Μετράει μόνο πραγματική δραστηριότητα (`X-Active`) |
| Κωδικοί B2B | Windows **DPAPI** (ή AES τοπικό κλειδί εκτός Windows) **+ vault AES-GCM με κλειδί από το PIN**· το κλειδί μένει μόνο στη μνήμη μετά το ξεκλείδωμα |
| Διαρροές | Ο κωδικός δεν επιστρέφεται ποτέ στο UI/αναφορές/logs· `view()` αφαιρεί το `b2bPass` |
| B2B login | Μόνο https (localhost για δοκιμές)· redirects μόνο στο ίδιο origin· cookies δεν φεύγουν αλλού |
| Admin κωδικοί sites | **Δεν ζητούνται, δεν αποθηκεύονται** |

Αν ξεχαστεί το PIN: ξαναγράφονται μόνο οι κωδικοί B2B.

Αυτοματοποιημένο τεστ ροής (`tests/sec.js`): ~50 έλεγχοι — PIN, 423, lockout, επανεκκίνηση, rewrap, B2B μετά το ξεκλείδωμα, αφαίρεση PIN, διαρροές στο data folder/log.

## 11. Περιορισμοί & γνωστά σημεία

- Δεν έχει δοκιμαστεί σε πραγματικά **Windows/Chrome** (DPAPI, άνοιγμα καρτέλας) — μόνο σε Linux με mocks.
- Αναζήτηση αντιπροσώπων με δωρεάν μηχανές: μπορεί να μπλοκαριστεί· ~354 μάρκες θέλουν εβδομάδες να ψαχτούν όλες.
- Η αυτόματη B2B σύνδεση δουλεύει μόνο σε B2B φτιαγμένα με **WordPress/WooCommerce**· άλλα συστήματα → PDF/Excel.
- Matching: ανάμεσα στα «Ίδιο» υπάρχουν περιπτώσεις διαφορετικού χρώματος/σχεδίου — γι' αυτό υπάρχει ουρά επιβεβαίωσης και το `careful` στο export.
- Προσοχή στην ανάπτυξη: το εργαλείο Write μετατρέπει `\uXXXX` σε πραγματικούς χαρακτήρες — αποφεύγονται escapes ή διορθώνονται μετά.
