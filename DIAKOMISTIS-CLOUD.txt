SF ΚΕΝΤΡΟ — ΚΟΙΝΑ ΔΕΔΟΜΕΝΑ ΓΙΑ ΟΛΟΥΣ ΤΟΥΣ ΥΠΟΛΟΓΙΣΤΕΣ (λειτουργία διακομιστή)
================================================================================

ΤΙ ΑΛΛΑΖΕΙ
Μέχρι τώρα κάθε υπολογιστής είχε το δικό του πρόγραμμα και τα δικά του δεδομένα. Ένας κοινός φάκελος (OneDrive)
δουλεύει μόνο με ΕΝΑΝ υπολογιστή ανοιχτό κάθε φορά — αλλιώς ο ένας σβήνει τις αλλαγές του άλλου.

Στη λειτουργία διακομιστή το πρόγραμμα τρέχει ΜΙΑ φορά (στο cloud ή σε ένα PC) και όλοι οι υπολογιστές, και των
δύο μαγαζιών, το ανοίγουν σε Chrome/Edge με δικό τους όνομα και κωδικό:
- Ό,τι αλλάζει ένας (έγκριση, τιμή, αντιπρόσωπος) εμφανίζεται ΑΜΕΣΩΣ στους άλλους.
- Οι αυτόματες εργασίες (ανάγνωση sites, τιμοκατάλογοι, έρευνα αγοράς, αναζήτηση περιγραφών) γίνονται μία φορά,
  στον διακομιστή — όχι σε κάθε υπολογιστή. Οι υπολογιστές του μαγαζιού μένουν ελαφριοί (μόνο ένας browser).
- Το AI (Ollama), αν το βάλεις, χρειάζεται ΜΟΝΟ σε ένα μέρος (στον διακομιστή ή σε έναν δυνατό υπολογιστή).

Υπάρχουν τρεις τρόποι. Προτείνεται ο 1.

--------------------------------------------------------------------------------
1. CLOUD (προτείνεται): μικρός διακομιστής στο internet, ~5 € τον μήνα, ανοιχτός 24/7
--------------------------------------------------------------------------------
Χρειάζεσαι: έναν VPS με Linux (π.χ. Hetzner CX22 ή αντίστοιχο, 2 CPU / 4 GB RAM — αρκεί άνετα),
και ένα subdomain σας, π.χ. kentro.specialforces.gr.

a) Στον πάροχο του domain: φτιάξε εγγραφή DNS τύπου A: kentro → η διεύθυνση IP του VPS.
b) Στον VPS (μία φορά):
     curl -fsSL https://get.docker.com | sh
     git clone <το αποθετήριο> sf-kentro      (ή ανέβασε τον φάκελο με WinSCP)
     cd sf-kentro/deploy
     cp env.example .env       και γράψε στο .env: KENTRO_HOST=kentro.specialforces.gr
     docker compose up -d --build
c) Άνοιξε https://kentro.specialforces.gr — το https μπαίνει μόνο του (δωρεάν πιστοποιητικό).
   Την πρώτη φορά ζητάει «κωδικό αρχικής ρύθμισης»: τον βλέπεις με
     docker compose logs kentro
   (ή βάλε από πριν KENTRO_ADMIN_USER / KENTRO_ADMIN_PASSWORD στο .env).
d) Ρυθμίσεις → Χρήστες: πρόσθεσε έναν λογαριασμό για κάθε άτομο. «Χρήστης» = όλη η δουλειά,
   «Διαχειριστής» = και ρυθμίσεις / ασφάλεια / χρήστες.

Μεταφορά των τωρινών δεδομένων (μία φορά):
- Στον υπολογιστή που δουλεύεις τώρα: Ρυθμίσεις → Δεδομένα → «Άνοιγμα φακέλου» και κλείσε το πρόγραμμα.
- Αντέγραψε όλα τα .json αρχεία του φακέλου στον διακομιστή, π.χ.:
     docker compose cp ./SF-Kentro-dedomena/. kentro:/data/
     docker compose exec -u root kentro chown -R node:node /data
     docker compose restart kentro
- ΣΗΜΑΝΤΙΚΟ: οι κωδικοί B2B των αντιπροσώπων είναι κλειδωμένοι στα Windows αυτού του υπολογιστή και δεν
  ανοίγουν αλλού (έτσι πρέπει). Στον διακομιστή ξαναγράψ’ τους μία φορά (Αντιπρόσωποι → B2B).

Ενημέρωση σε νέα έκδοση:   cd sf-kentro && git pull && cd deploy && docker compose up -d --build
Αντίγραφα ασφαλείας: γίνονται μόνα τους κάθε μέρα (14 μέρες) μέσα στον διακομιστή. Κράτα και ένα αντίγραφο έξω:
     docker compose cp kentro:/data ./antigrafo-$(date +%F)

--------------------------------------------------------------------------------
2. ΕΝΑΣ ΥΠΟΛΟΓΙΣΤΗΣ ΤΟΥ ΜΑΓΑΖΙΟΥ ως διακομιστής (δωρεάν· πρέπει να μένει ανοιχτός)
--------------------------------------------------------------------------------
a) Στον υπολογιστή-διακομιστή: διπλό κλικ στο «SF-Kentro-Server.cmd» (αντί για το SF-Kentro.cmd).
   Τα Windows θα ρωτήσουν για το τείχος προστασίας: «Να επιτρέπεται» μόνο για «Ιδιωτικά δίκτυα».
   Το μαύρο παράθυρο γράφει τον κωδικό αρχικής ρύθμισης την πρώτη φορά.
b) Στους άλλους υπολογιστές του ίδιου δικτύου: Chrome → http://ΟΝΟΜΑ-Ή-IP-ΤΟΥ-ΔΙΑΚΟΜΙΣΤΗ:17321
   (η IP φαίνεται με την εντολή ipconfig στον διακομιστή).
c) Για το ΑΛΛΟ μαγαζί (άλλο δίκτυο): εγκατέστησε το δωρεάν Tailscale (tailscale.com) στον διακομιστή και στους
   υπολογιστές του άλλου μαγαζιού. Ανοίγουν http://ΟΝΟΜΑ-TAILSCALE:17321 — η σύνδεση είναι κρυπτογραφημένη και
   ΔΕΝ ανοίγει τίποτα στο internet. Μην ανοίξεις ποτέ θύρα (port forwarding) στο ρούτερ για το πρόγραμμα.

--------------------------------------------------------------------------------
3. ΟΠΩΣ ΠΡΙΝ: ένας υπολογιστής, χωρίς κοινά δεδομένα
--------------------------------------------------------------------------------
Το SF-Kentro.cmd δουλεύει ακριβώς όπως πάντα (μόνο αυτός ο υπολογιστής, με PIN).

--------------------------------------------------------------------------------
ΑΣΦΑΛΕΙΑ ΣΤΗ ΛΕΙΤΟΥΡΓΙΑ ΔΙΑΚΟΜΙΣΤΗ
--------------------------------------------------------------------------------
- Κάθε άτομο με δικό του όνομα και κωδικό (τουλάχιστον 10 χαρακτήρες). Οι κωδικοί δεν αποθηκεύονται·
  μόνο ένα «αποτύπωμα» scrypt που δεν γυρίζει πίσω.
- 5 λάθος κωδικοί → αναμονή 1 λεπτού που διπλασιάζεται (ανά χρήστη και ανά διεύθυνση).
- Η σύνδεση λήγει μετά από αδράνεια (Ρυθμίσεις → Ασφάλεια, προεπιλογή 30′).
- Cookie σύνδεσης HttpOnly + SameSite=Strict (+ Secure με https) και ξεχωριστό κλειδί ανά σύνδεση σε κάθε
  αίτημα: άλλες σελίδες του browser δεν μπορούν να κάνουν τίποτα στο πρόγραμμα.
- Ρυθμίσεις, ασφάλεια, χρήστες, επαναφορά αντιγράφων: μόνο διαχειριστές.
- Κωδικοί B2B: κρυπτογραφημένοι στον διακομιστή, και επιπλέον με PIN (Ρυθμίσεις → Ασφάλεια). Μετά από κάθε
  επανεκκίνηση του διακομιστή ένας διαχειριστής βάζει το PIN μία φορά, για να διαβάζονται τα B2B αυτόματα.
- Κωδικοί διαχειριστή (admin) των sites: δεν χρειάζονται και δεν αποθηκεύονται πουθενά. Το πρόγραμμα ΔΕΝ γράφει
  τίποτα στα sites· φτιάχνει αρχεία που ανεβάζεις εσύ.

ΡΥΘΜΙΣΕΙΣ ΔΙΑΚΟΜΙΣΤΗ (μεταβλητές περιβάλλοντος — για προχωρημένους)
  SFK_MODE=server            λειτουργία διακομιστή
  SFK_PORT=17321             θύρα
  SFK_HOST=0.0.0.0           σε ποιες διευθύνσεις ακούει
  SFK_DATA=/data             φάκελος δεδομένων
  SFK_ALLOWED_HOSTS=kentro.specialforces.gr   ποιες διευθύνσεις δέχεται (κενό = όλες, για το τοπικό δίκτυο)
  SFK_TRUST_PROXY=1          πίσω από Caddy / nginx (σωστή IP και https)
  SFK_SECURE_COOKIE=1        cookie μόνο με https
  SFK_ADMIN_USER / SFK_ADMIN_PASSWORD   ο πρώτος διαχειριστής χωρίς κωδικό αρχικής ρύθμισης
