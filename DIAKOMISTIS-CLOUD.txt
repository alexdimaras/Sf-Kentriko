SF ΚΕΝΤΡΟ — ΑΠΟ ΚΙΝΗΤΟ ΚΑΙ ΑΠΟ ΟΛΟΥΣ ΤΟΥΣ ΥΠΟΛΟΓΙΣΤΕΣ, ΣΥΓΧΡΟΝΙΣΜΕΝΑ, ΔΩΡΕΑΝ
================================================================================

ΠΩΣ ΔΟΥΛΕΥΕΙ
Το πρόγραμμα τρέχει σε ΕΝΑ μέρος, τον «διακομιστή». Όλα τα PC και τα κινητά το ανοίγουν σαν σελίδα, ο καθένας με
το δικό του όνομα και κωδικό. Γι' αυτό είναι πάντα συγχρονισμένα: ό,τι αλλάζει ένας (έγκριση, τιμή, αντιπρόσωπος)
φαίνεται ΑΜΕΣΩΣ σε όλους, και ένα κινητό που ξυπνάει ενημερώνεται μόνο του.
- Οι αυτόματες εργασίες (ανάγνωση sites, τιμοκατάλογοι, έρευνα αγοράς, διορθώσεις) γίνονται μία φορά, στον
  διακομιστή. Τα PC του μαγαζιού μένουν ελαφριά (μόνο ένας browser).
- Το AI (Ollama), αν το βάλεις, χρειάζεται ΜΟΝΟ σε ένα μέρος.
- Ένας κοινός φάκελος (OneDrive) ΔΕΝ είναι λύση: με δύο PC ανοιχτά ο ένας σβήνει τις αλλαγές του άλλου.

================================================================================
Α. ORACLE CLOUD «ALWAYS FREE» — ΒΗΜΑ ΒΗΜΑ (μία φορά, περίπου 30 λεπτά)
================================================================================
1. ΛΟΓΑΡΙΑΣΜΟΣ
   - oracle.com/cloud/free → «Start for free».
   - Home Region: μια κοντινή, π.χ. «Germany Central (Frankfurt)» ή «Italy Northwest (Milan)». ΔΕΝ αλλάζει μετά.
   - Ζητάει κάρτα για επιβεβαίωση ταυτότητας. Οι πόροι «Always Free» δεν χρεώνονται.
2. ΜΗΧΑΝΗΜΑ: Compute → Instances → Create instance
   - Image: «Canonical Ubuntu» (24.04).
   - Shape: Ampere → VM.Standard.A1.Flex, 1 OCPU και 6 GB μνήμη (μέσα στο δωρεάν και περισσεύει).
     Αν γράψει «Out of capacity»: άλλο «Availability domain», ή ξανά σε λίγες ώρες, ή το VM.Standard.E2.1.Micro
     (επίσης δωρεάν· αρκεί — το πρόγραμμα βάζει μόνο του swap για τη μικρή μνήμη).
   - Add SSH keys: «Generate a key pair for me» → «Save private key». Κράτα το αρχείο .key: είναι το κλειδί.
   - Create. Όταν γίνει «Running», σημείωσε τη «Public IP address».
3. ΠΟΡΤΕΣ 80 ΚΑΙ 443 (για να ανοίγει η σελίδα)
   Στη σελίδα του instance πάτα το Subnet → Security Lists → «Default Security List» → «Add Ingress Rules»:
     Source CIDR 0.0.0.0/0 · IP Protocol TCP · Destination Port Range 80,443 → Add Ingress Rules.
4. ΔΙΕΥΘΥΝΣΗ (μία από τις δύο, και οι δύο δωρεάν)
   - Με το domain σας: εκεί που ρυθμίζετε τα DNS του site, πρόσθεσε εγγραφή τύπου A με όνομα «kentro» και τιμή
     τη Public IP. Η διεύθυνση γίνεται π.χ. kentro.specialforces.gr.
   - Χωρίς domain: duckdns.org (σύνδεση με Google ή GitHub) → γράψε ένα όνομα, π.χ. sf-kentro, και στο
     «current ip» τη Public IP. Η διεύθυνση γίνεται sf-kentro.duckdns.org.
5. ΑΝΕΒΑΣΜΑ ΚΑΙ ΕΓΚΑΤΑΣΤΑΣΗ — ένα διπλό κλικ
   Στον φάκελο SF-Kentro του υπολογιστή σου: διπλό κλικ στο «SF-Kentro-Cloud.cmd». Ζητάει:
     - την Public IP,
     - το αρχείο .key (σύρε το μέσα στο μαύρο παράθυρο και πάτα Enter),
     - τη διεύθυνση (π.χ. kentro.specialforces.gr).
   Την πρώτη φορά ρωτάει «Are you sure you want to continue connecting» → γράψε yes και Enter.
   Θέλει 5-10 λεπτά. Στο τέλος γράφει τη διεύθυνση και τον «κωδικό αρχικής ρύθμισης».
   (Το https μπαίνει μόνο του, με δωρεάν πιστοποιητικό Let's Encrypt.)
6. ΠΡΩΤΗ ΣΥΝΔΕΣΗ: άνοιξε τη διεύθυνση → γράψε τον κωδικό αρχικής ρύθμισης → φτιάξε τον λογαριασμό σου
   (διαχειριστής).
7. ΤΑ ΔΕΔΟΜΕΝΑ ΣΟΥ (μία φορά)
   - Στον υπολογιστή που δουλεύεις τώρα (SF-Kentro.cmd): Ρυθμίσεις → Δεδομένα → «Λήψη αντιγράφου».
   - Στον διακομιστή, από τον browser: Ρυθμίσεις → Δεδομένα → «Επαναφορά από αρχείο…» → διάλεξε το αρχείο.
   - Οι κωδικοί B2B των αντιπροσώπων είναι κλειδωμένοι στα Windows του παλιού υπολογιστή και ΔΕΝ ανοίγουν αλλού
     (έτσι πρέπει). Ξαναγράψ’ τους μία φορά στον διακομιστή (Αντιπρόσωποι → B2B).
8. ΧΡΗΣΤΕΣ: Ρυθμίσεις → Χρήστες → ένας λογαριασμός για κάθε άτομο. «Χρήστης» = όλη η δουλειά,
   «Διαχειριστής» = και ρυθμίσεις / ασφάλεια / χρήστες / αντίγραφα.
9. ΚΙΝΗΤΑ: Ρυθμίσεις → Κινητό → σκάναρε το QR (δες «ΣΤΟ ΚΙΝΗΤΟ» πιο κάτω).

ΜΟΝΟ ΑΠΟ ΚΙΝΗΤΟ (χωρίς υπολογιστή, χωρίς SSH): στο βήμα 2, στο «Advanced options → Management», τσέκαρε «Paste cloud-init
script» και επικόλλησε το περιεχόμενο του αρχείου deploy/cloud-init.sh (αλλάζεις μόνο τις τρεις πρώτες γραμμές: διεύθυνση,
όνομα και κωδικό διαχειριστή). Στο SSH keys διάλεξε «No SSH keys». Το μηχανήμα στήνεται μόνο του σε 10-15 λεπτά και
ανοίγεις https://η-διεύθυνσή-σου/. Η διεύθυνση: duckdns.org (σύνδεση με Google), όνομα της επιλογής σου και, μόλις δεις
τη Public IP του μηχανήματος, γράφεις την IP στο duckdns.

ΝΕΑ ΕΚΔΟΣΗ: βγάλε τον νέο φάκελο και ξανά διπλό κλικ στο SF-Kentro-Cloud.cmd (θυμάται IP, κλειδί και διεύθυνση·
πατάς μόνο Enter). Τα δεδομένα μένουν στον διακομιστή.

ΤΑ «ΨΙΛΑ ΓΡΑΜΜΑΤΑ» ΤΟΥ ΔΩΡΕΑΝ — τίμια
- Η Oracle μπορεί να σταματήσει («reclaim») δωρεάν μηχανήματα που μένουν σχεδόν αδρανή για μέρες. Όσοι το
  χρησιμοποιούν αναφέρουν ότι με «Upgrade to Pay As You Go» (στον λογαριασμό) αυτό δεν γίνεται και τα «Always
  Free» μένουν δωρεάν. Αν το κάνεις, βάλε και ειδοποίηση κόστους στο 1 € (Billing → Budgets) για σιγουριά.
- Κατέβαζε μια «Λήψη αντιγράφου» κάθε εβδομάδα (Ρυθμίσεις → Δεδομένα) και κράτα τη εκτός cloud (USB, OneDrive).
  Ο διακομιστής κρατάει μόνος του και ένα αντίγραφο κάθε μέρα (14 μέρες).
- Το δωρεάν πακέτο αλλάζει πού και πού (αναφέρθηκε μείωση των δωρεάν Ampere το 2026). Το 1 OCPU / 6 GB που
  προτείνεται εδώ χωράει και στο μικρότερο.
- Μετά από κάθε επανεκκίνηση του διακομιστή (και μετά από κάθε νέα έκδοση), αν έχεις PIN για τα B2B, ένας
  διαχειριστής το βάζει μία φορά (Ρυθμίσεις → Ασφάλεια) για να διαβάζονται τα B2B στην ημερήσια ενημέρωση.

Δ. GITHUB CODESPACES — ΔΩΡΕΑΝ, ΧΩΡΙΣ ΚΑΡΤΑ, ΜΟΝΟ ΑΠΟ ΚΙΝΗΤΟ (για αρχή / για λίγες μέρες)
================================================================================
Ο λογαριασμός GitHub έχει δωρεάν μηνιαίο όριο για Codespaces (αναφέρεται 120 ώρες πυρήνα = 60 ώρες σε μηχάνημα
2 πυρήνων, και 15 GB αποθήκευση). Το πρόγραμμα τρέχει εκεί, με https, και ανοίγει από το κινητό σου.
1. github.com → Settings → Codespaces → Secrets → New secret, δύο φορές (Repository access: Sf-Kentriko):
     KENTRO_ADMIN_USER      π.χ. alex
     KENTRO_ADMIN_PASSWORD  τουλάχιστον 10 χαρακτήρες
   Στην ίδια σελίδα, «Default idle timeout»: βάλε 240 λεπτά (αλλιώς κοιμάται μετά από 30′).
2. github.com/alexdimaras/Sf-Kentriko → διάλεξε το branch  claude/friendly-sagan-bfjrkj  → Code → Codespaces →
   «Create codespace on claude/friendly-sagan-bfjrkj». Η πρώτη φορά θέλει 3-5 λεπτά.
3. Όταν είναι έτοιμο, στο παράθυρο του Codespace: καρτέλα «Ports» → θύρα 17321 → εικονίδιο υδρογείου (Open in Browser).
   Αντίγραψε τη διεύθυνση (https://…-17321.app.github.dev) και βάλ' τη στους σελιδοδείκτες / στην αρχική οθόνη.
4. Συνδέεσαι με το KENTRO_ADMIN_USER και τον κωδικό. Μετά: «Ανάγνωση από τα sites».
Κάθε επόμενη μέρα: github.com/codespaces → το Codespace → «Start» (ή απλώς άνοιξε τη διεύθυνση του βήματος 3).
ΟΡΙΑ: κοιμάται όταν δεν δουλεύεις (οι ημερήσιες αυτόματες εργασίες τρέχουν μόνο όσο είναι ξύπνιο)· σβήνεται μετά από
30 μέρες χωρίς χρήση — κατέβαζε «Λήψη αντιγράφου» (Ρυθμίσεις → Δεδομένα)· αν περάσεις το δωρεάν όριο, σταματά
(δεν χρεώνεσαι αν το όριο ξόδων μένει στο 0). Η σελίδα ανοίγει μόνο όταν είσαι συνδεδεμένος στο GitHub και μετά με τον
δικό σου κωδικό στο πρόγραμμα. Το αποθετήριο είναι δημόσιο, αλλά δεν περιέχει δεδομένα ή κωδικούς.
Τα τωρινά δεδομένα του υπολογιστή δεν υπάρχουν εκεί: ξεκινάς καθαρός. Όταν γυρίσεις σπίτι, «Λήψη αντιγράφου» από τον
υπολογιστή και «Επαναφορά από αρχείο» εδώ (ή ανάποδα).

Β. ΕΝΑ PC ΤΟΥ ΜΑΓΑΖΙΟΥ ΩΣ ΔΙΑΚΟΜΙΣΤΗΣ (δωρεάν, χωρίς κάρτα, χωρίς λογαριασμούς)
================================================================================
1. Κλείσε το SF-Kentro (αν είναι ανοιχτό) και άνοιξε το «SF-Kentro-Server.cmd» από τον ίδιο φάκελο.
   Τα δεδομένα είναι τα ίδια: δεν μεταφέρεις τίποτα. Ανοίγει μόνο του και ο browser.
2. Τα Windows ρωτάνε για το τείχος προστασίας: τσέκαρε «Ιδιωτικά δίκτυα» → «Να επιτρέπεται η πρόσβαση».
   (Αν το δίκτυο του μαγαζιού είναι δηλωμένο «Δημόσιο», άλλαξέ το σε «Ιδιωτικό»: Ρυθμίσεις → Δίκτυο.)
3. Πρώτη φορά: φτιάξε τον λογαριασμό σου με τον κωδικό που γράφει το μαύρο παράθυρο.
4. Ρυθμίσεις → Χρήστες: ένας λογαριασμός για κάθε άτομο.
5. Ρυθμίσεις → Κινητό: σκάναρε το QR με κάθε κινητό. Τα άλλα PC του μαγαζιού ανοίγουν τη διεύθυνση που γράφει
   εκεί (π.χ. http://192.168.1.20:17321).
6. Για να ξεκινάει μόνο του το πρωί: Win+R → γράψε shell:startup → Enter → βάλε εκεί μια συντόμευση του
   SF-Kentro-Server.cmd.
ΟΡΙΑ: μόνο μέσα στο δίκτυο αυτού του μαγαζιού (όχι από Wi-Fi επισκεπτών, όχι από τα δεδομένα του κινητού) και
μόνο όσο είναι ανοιχτό αυτό το PC. Η ημερήσια έρευνα γίνεται όταν ανοίξει το πρωί.
Για το ΑΛΛΟ μαγαζί και για το κινητό έξω από το μαγαζί: το Α.
ΠΟΤΕ μην ανοίξεις θύρα (port forwarding) στο ρούτερ για το πρόγραμμα.
(Υπάρχουν και εφαρμογές ιδιωτικού δικτύου, όπως το Tailscale, αλλά το δωρεάν πακέτο τους είναι για προσωπική
χρήση· για επιχείρηση θέλουν συνδρομή. Γι' αυτό η δωρεάν πρόταση για «από παντού» είναι το Α.)

ΣΤΟ ΚΙΝΗΤΟ (μία φορά, ένα λεπτό)
================================================================================
1. Σκάναρε το QR (Ρυθμίσεις → Κινητό, σε έναν υπολογιστή) με την κάμερα, ή γράψε τη διεύθυνση στον browser.
2. Όνομα και κωδικός, και τσέκαρε «Μείνε συνδεδεμένος σε αυτή τη συσκευή»: μένεις μέσα έως 12 ώρες χωρίς χρήση.
   Μόνο στο δικό σου κινητό, όχι σε ξένη συσκευή.
3. Βάλ' το στην αρχική οθόνη, για να ανοίγει σαν εφαρμογή:
   - iPhone (Safari): κουμπί Κοινοποίηση (τετράγωνο με βέλος) → «Προσθήκη στην οθόνη Αφετηρίας».
   - Android (Chrome): μενού ⋮ → «Εγκατάσταση εφαρμογής» ή «Προσθήκη στην αρχική οθόνη».
Στο κινητό: κάτω μπάρα με Σήμερα / Διορθώσεις / Τιμές / Προϊόντα / Μενού. Ό,τι εγκρίνεις εκεί φαίνεται αμέσως
στα PC. Τα αρχεία για WooCommerce τα φτιάχνεις καλύτερα από PC (εκεί τα ανεβάζεις στο site).
Χάθηκε ένα κινητό; Ρυθμίσεις → Χρήστες → «Ανοιχτές συνδέσεις» → «Αποσύνδεση» δίπλα του, και άλλαξε τον κωδικό.

ΑΣΦΑΛΕΙΑ ΣΤΗ ΛΕΙΤΟΥΡΓΙΑ ΔΙΑΚΟΜΙΣΤΗ
================================================================================
- Κάθε άτομο με δικό του όνομα και κωδικό (τουλάχιστον 10 χαρακτήρες). Οι κωδικοί δεν αποθηκεύονται·
  μόνο ένα «αποτύπωμα» scrypt που δεν γυρίζει πίσω.
- 5 λάθος κωδικοί → αναμονή 1 λεπτού που διπλασιάζεται (ανά χρήστη και ανά διεύθυνση).
- Η σύνδεση λήγει μετά από αδράνεια (Ρυθμίσεις → Ασφάλεια, προεπιλογή 30′). Με «Μείνε συνδεδεμένος» στο
  κινητό: 12 ώρες. Ο διαχειριστής βλέπει κάθε συνδεδεμένη συσκευή και αποσυνδέει όποια θέλει.
- Cookie σύνδεσης HttpOnly + SameSite=Strict (+ Secure με https) και ξεχωριστό κλειδί ανά σύνδεση σε κάθε
  αίτημα: άλλες σελίδες του browser δεν μπορούν να κάνουν τίποτα στο πρόγραμμα.
- Στο cloud: μόνο https (κρυπτογραφημένα), δεκτή μόνο η δική σας διεύθυνση.
- Ρυθμίσεις, ασφάλεια, χρήστες, αντίγραφα και επαναφορά: μόνο διαχειριστές.
- Κωδικοί B2B: κρυπτογραφημένοι στον διακομιστή, και επιπλέον με PIN (Ρυθμίσεις → Ασφάλεια).
- Κωδικοί διαχειριστή (admin) των sites: δεν χρειάζονται και δεν αποθηκεύονται πουθενά. Το πρόγραμμα ΔΕΝ γράφει
  τίποτα στα sites· φτιάχνει αρχεία που ανεβάζεις εσύ.

ΓΙΑ ΠΡΟΧΩΡΗΜΕΝΟΥΣ
================================================================================
Χωρίς το SF-Kentro-Cloud.cmd (οποιοσδήποτε διακομιστής Ubuntu — και πληρωμένος VPS, αν κάποτε χρειαστεί):
  ανέβασε τους φακέλους app και deploy και τρέξε:   sudo bash deploy/install-server.sh kentro.example.gr
Στον διακομιστή (μέσα στο sf-kentro/deploy):
  Κατάσταση / logs:        sudo docker compose logs kentro        (https: sudo docker compose logs caddy)
  Επανεκκίνηση:            sudo docker compose restart
  Όλος ο φάκελος δεδομένων: sudo docker compose cp kentro:/data ./antigrafo-$(date +%F)
Ρυθμίσεις διακομιστή (μεταβλητές περιβάλλοντος):
  SFK_MODE=server            λειτουργία διακομιστή
  SFK_PORT=17321             θύρα
  SFK_HOST=0.0.0.0           σε ποιες διευθύνσεις ακούει
  SFK_DATA=/data             φάκελος δεδομένων
  SFK_ALLOWED_HOSTS=kentro.specialforces.gr   ποιες διευθύνσεις δέχεται (κενό = όλες, για το τοπικό δίκτυο)
  SFK_TRUST_PROXY=1          πίσω από Caddy / nginx (σωστή IP και https)
  SFK_SECURE_COOKIE=1        cookie μόνο με https
  SFK_ADMIN_USER / SFK_ADMIN_PASSWORD   ο πρώτος διαχειριστής χωρίς κωδικό αρχικής ρύθμισης
