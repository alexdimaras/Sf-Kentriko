# Δοκιμές ταχύτητας, μνήμης και κινητού

- `mockwoo.js` — ψεύτικο WooCommerce με όσα προϊόντα/παραλλαγές θέλουμε (τα αληθινά: SF 9.908 / 26.464, ΣΤ 7.412 / 41.653).
- `render-sim.js` — όπως το δωρεάν Render: 512 MB, άδειος δίσκος σε κάθε εκκίνηση, φύλαξη σε (ψεύτικο) GitHub.
  Πλήρης ανάγνωση → φύλαξη → επανεκκίνηση → επαναφορά. Με τα αληθινά sites:
  `NODE_USE_ENV_PROXY=1 HEAP=280 TRACE=1 node render-sim.js .. https://specialforces.gr https://stratiotikaeidi.gr`
  (τα δεδομένα μένουν στο os.tmpdir()/e2e-2 για τις επόμενες δοκιμές).
- `screens.js <φάκελος δεδομένων>` — όλες οι οθόνες στο κινητό (Playwright): χρόνος μέχρι να γεμίσουν, σφάλματα.
- `wake.js <φάκελος δεδομένων>` — «φεύγω από την εφαρμογή, το πρόγραμμα κοιμάται, γυρίζω»: δεν πρέπει να μείνει λευκή οθόνη.

Μετρήσεις (Νοέμβριος 2026, αληθινά sites): ανάγνωση 5′, μέγιστη μνήμη 396 MB, φύλαξη 18 MB,
μετά από ψυχρή εκκίνηση ~7,6 s CPU εδώ (≈10× στο Render free, 0,1 CPU).
