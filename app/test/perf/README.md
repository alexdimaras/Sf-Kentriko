# Δοκιμές ταχύτητας, μνήμης και κινητού

Ό,τι μετράει σε μικρό μηχάνημα (χρόνος, παγώματα, μνήμη) φαίνεται μόνο κάτω από τα ίδια όρια. Γι' αυτό:

- `box.sh <εντολή>` — τρέχει μια εντολή με τα όρια του δωρεάν Render: 0,1 CPU και 512 MB (cgroups, θέλει root).
- `routes.js <δεδομένα>` — ξεκινά το πρόγραμμα στο κουτί, μετρά κάθε οθόνη 3 φορές και μία έγκριση.
- `watch.js <δεδομένα> <δευτ.> [ΚΛΕΙΔΙ=τιμή…]` — «μια μέρα» στο κουτί όπως στην παραγωγή (αυτόματη ανάγνωση των
  αληθινών sites, χτίσιμο, φύλαξη): κάθε 2 s χρόνος απάντησης, μνήμη, τρέχουσα εργασία· στο τέλος σύνοψη.
- `phone.js <δεδομένα> [BOX=1]` — πραγματικός browser κινητού (Playwright, iPhone 13): πόσο γρήγορα γεμίζει κάθε
  οθόνη, πότε φεύγει μια εγκεκριμένη αλλαγή, ξανάνοιγμα με το πρόγραμμα κλειστό.
- `shots.js <δεδομένα> <φάκελος>` — εικόνες των οθονών με τα αληθινά δεδομένα (για το σχέδιο).
- `fakegithub.js [θύρα]` — ένα μικρό «GitHub» για τη φύλαξη (`SFK_GITHUB_API=http://127.0.0.1:θύρα`).
- `mockwoo.js`, `render-sim.js`, `screens.js`, `wake.js` — τα παλιότερα: ψεύτικο WooCommerce, προσομοίωση Render
  χωρίς όριο CPU, όλες οι οθόνες, «φεύγω και γυρίζω».

Για τα αληθινά sites από αυτό το περιβάλλον: `NODE_USE_ENV_PROXY=1 NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt`
(το `watch.js` τα βάζει μόνο του).

## Μετρήσεις (Νοέμβριος 2026) — κουτί 0,1 CPU / 512 MB, αληθινά δεδομένα (SF 9.908 / ΣΤ 7.412 προϊόντα)

| Τι | Πριν (1.3.0) | Τώρα (1.4.0) |
|---|---|---|
| Επανεκκίνηση: πρώτη απάντηση | 14–25 s | 2 s |
| Επανεκκίνηση: οθόνες έτοιμες | ~117–128 s, παγωμένο | 26–29 s (με φυλαγμένα αποτελέσματα), απαντά συνεχώς |
| Έγκριση μίας διόρθωσης → ενημερωμένη οθόνη | 33 s | 10–14 ms στο κινητό (αισιόδοξα)· ~1,5 s στον διακομιστή |
| Διορθώσεις (λίστα) | 1,3–3,6 s | 15–45 ms |
| Προϊόντα (λίστα / αναζήτηση) | 0,65–1,0 s | 10 ms |
| Αντιπρόσωποι | 0,35–0,85 s | 2 ms (μετά την πρώτη φορά) |
| Οθόνη που έχει ξανανοίξει (κινητό) | όσο το αίτημα | 1–14 ms |
| Ξανάνοιγμα με το πρόγραμμα κλειστό/κοιμισμένο | σφάλμα browser | 46–61 ms, με τις τελευταίες οθόνες |
| Πλήρης ανάγνωση και των δύο sites | έσκαγε στο 2ο site (μνήμη), ξανά από την αρχή, χωρίς τέλος | 226 s + 162 s, χτίσιμο 109 s· όλα σε 11′ |
| Μέγιστη μνήμη στον κύκλο αυτό | >512 MB / όριο heap | 426 MB |
| Μνήμη ηρεμίας (heap) | 184 MB | 121 MB |
| Φύλαξη στο GitHub μετά από μια έγκριση | ολόκληρο πακέτο ~18 MB | 1–2 αρχεία, ~1 KB |

Τι ΔΕΝ είναι μετρημένο στο κουτί: η πλήρης έρευνα αγοράς με 24 ανταγωνιστές μέχρι τέλους (βλ. `docs/FILOXENIA.md`,
πρόταση 2) και ο πρώτος πλήρης υπολογισμός χωρίς φυλαγμένα αποτελέσματα μετρήθηκε σε ~3 λεπτά (γίνεται μία φορά).
